1. 项目背景
当前 AI Coding 工具普遍存在以下问题：
1. 单 Agent 模式，缺乏协作能力
2. AI 输出不可控
3. 缺少工程化规范
4. 多轮上下文混乱
5. 缺少任务拆解与调度能力
6. AI 生成结果缺乏审核与验证
7. 产物无法在协作流中直接展示
因此，本项目目标是：
构建一个以 IM（即时通讯）为核心交互形式的多 Agent 协作平台，使用户能够像在飞书/微信中进行群聊一样，与多个 AI Agent 协同完成软件开发任务。
平台重点不是简单 AI 对话，而是：
- AI Workflow
- Agent 协作调度
- Structured Output
- AI 工程化约束
- Artifact 内联展示
- 可验证 AI 协作体系

Retry Rules
规则：
JSON非法
→ Retry

Review失败
→ Retry

→ Fallback Agent

---
Conflict Rules

- 同文件串行修改

- 冲突人工确认

---

- 执行危险Shell
- 输出恶意代码

12. 项目核心价值总结
AgentHub 不只是一个 AI Chat 产品。
其核心目标是：
构建一个：
- 可调度
- 可验证
- 可追踪
- 可复现
- 可协作
的 AI Coding 工程平台。
比赛重点不在于：
- Prompt 数量
- Agent 数量
- 页面复杂度
而在于：
是否形成完整 AI 工程协作体系。
